## 2. 自动化测试门槛

实现应提供可重复的一键测试，至少覆盖：

- 领域和模板填充单元测试；
- API 权限、输入校验和状态转换集成测试；
- 不调用真实 AI 的固定响应测试；
- 使用现有端点和真实视频的可选端到端测试；
- 三份生成 DOCX 的 XML/结构断言；
- 三份生成 DOCX 的渲染和逐页视觉检查。

真实 AI 验收不得成为每次普通单元测试的必需条件，但正式交付前必须至少成功运行一次。

## 3. 权限与安全

1. 检查员 A 创建检查后，检查员 B 无法通过列表、猜测 ID、文件 URL或 AI 助手读取、修改、删除或下载该检查数据。
2. 管理员可以管理用户、模板和知识库；检查员调用对应接口得到 403。
3. 未登录用户访问业务 API 或材料文件得到 401。
4. 恶意文件名不能写出数据目录；不支持或损坏的文件得到可理解错误。
5. 日志和错误响应中不出现 AI 密钥、会话令牌或服务器绝对敏感路径。

## 4. 媒体和事实

### 4.1 视频 1

处理 `1.mp4` 后：

- 生成非空完整转写和覆盖视频时间范围的时间锚片段；
- 候选事实应覆盖“消防控制室值班人员不在岗/休息”和“值班或持证情况需要核实”的核心语义；
- 不得把未明确出现的人名、证件编号、单位名称或最终执法结论编造成事实；
- 至少保留可供人工选择的关键画面，不能因质量阈值失配全部过滤；
- 点击事实证据能打开 `1.mp4` 的正确时间，而不是其他材料。

### 4.2 视频 4

处理 `4.mp4` 后：

- 候选事实应覆盖“大厅或现场存在堆放物品”和“区域被当作仓库或用途发生改变”的核心语义；
- 关键画面应提供能够支持人工选择照片证据的现场候选；
- 不得根据画面或转写自行给出未被确认的处罚结论。

### 4.3 人工处理

用户能编辑转写、确认问答角色、确认/撤回/补充事实及关联证据。修改历史显示操作人、时间、旧值和新值。

## 5. 法规知识

1. 初始化后可以按条款检索测试 PDF 的文本，并返回原文、条款和文档来源。
2. 上传内部制度时不能标记为正式法律法规。
3. 查询知识库不存在或召回不足的内容时，回答明确表示未找到，不生成虚假条款。
4. 点击法规证据能打开对应原始文档或定位到保存的条款。
5. 测试 PDF 缺少生产级来源元数据时显示“待核验”，不能展示为已确认的现行有效法律版本。

## 6. 模板识别

三份模板上传或初始化后必须识别并允许确认以下业务区域：

- 照片文书：照片、反映内容、拍摄地点、摄制人、拍摄时间、说明、确认人；
- 询问笔录：询问次数、起止时间、地点、询问人及工作单位、记录人及工作单位、被询问人基础信息、证件、地址、联系方式、问答正文；
- 监督检查记录表：编号、日期、检查类型、单位名称、负责人、地址、联系人及电话、检查内容和情况、备注及签名区域。

中低置信区域必须允许改名、禁用、补充或修正。界面只显示稳定中文业务名，不显示哈希或内部定位键。

## 7. Word 文书

### 7.1 监督检查记录表

- 被检查单位、地址、负责人、联系人、日期和检查内容填入正确位置；
- 所选检查类型恰好出现一个 `☑`，其余六个选项保持 `□`；
- 普通填充值不添加业务未要求的下划线；
- 表格、纸型、页边距、固定文字和标签保持原模板样式。

### 7.2 照片文书

- 选择三张照片时生成三套纵向证据区块，并嵌入三张实际图片；
- 文档中不再残留照片占位文本；
- 反映内容和说明可以逐照片修改；共享字段一次修改后对所有区块一致；
- 填充值带下划线，标签不带下划线；
- 图片等比例缩放，不拉伸、不越界、不遮挡文字。

### 7.3 询问笔录

- 表头字段进入正确位置且填充值带下划线；
- 正文统一为独立的“问：”和“答：”段落，并以人工确认角色和文字为准；
- 正文填入内容带下划线；
- 分别生成少于四页和超过四页的样本，当前页和总页数均正确；
- 长字段和跨页正文无裁切、重叠、异常大空白或表格破坏。

所有生成文书必须渲染为逐页图片检查，并至少使用 Word 或 WPS 实际打开一次验证分页、字体、图片和页脚域。

## 8. 状态和人工内容保护

1. 人工修改文书字段后重新生成，该字段保持原值并显示人工来源。
2. 已确认文书关联的事实、共享字段、选图、问答或模板映射变化后自动退回初稿，并记录原因。
3. 未发生相关变化时，后台任务不能无故改变已确认文书。
4. 多次点击重试或重新生成不会产生重复事实、重复任务或重复照片区块。

## 9. 失败和降级

分别模拟 ASR、LLM、视觉、Embedding 和文书生成失败：

- 对应步骤进入失败状态并显示可理解原因；
- 原始材料和其他成功步骤保留；
- 恢复服务后可以只重试失败步骤；
- 用户仍能查看、编辑和人工补充材料、转写、事实和文书字段；
- 系统不会用空值、旧结果或编造内容伪装成功。

## 10. 端到端交付门槛

从全新环境执行初始化后，使用管理员和检查员测试账号完成：登录 → 创建检查 → 上传视频 → 等待处理 → 确认事实 → 关联证据 → 检索法规 → 生成三类文书 → 人工修改和确认 → 导出 Word → 修改事实触发文书退回。

流程、权限测试、失败降级、自动化测试和 Word 视觉检查全部通过，且提供内网部署、配置、备份、恢复和升级说明后，才可验收。
