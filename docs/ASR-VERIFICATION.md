## 4. 带时间范围转写的解决方案：✅ 分段转写验证通过

PRD 要求"生成带时间范围的转写"（询问笔录、证据回溯）。由于模型本身不出时间戳，验证了**客户端分段**方案：

**做法**：ffmpeg 按 10s 硬窗切分音频 → 逐段调 `qwen3-asr-flash` → 时间段由切分位置天然确定。

**结果**（1.mp4，48s → 5 段）：

```text
[000.0 - 010.0] 负责这个门。
[010.0 - 020.0] 值班室的这个消防值班的人呢？今天今天礼拜天，他休息。…
[020.0 - 030.0] 同时24h在岗在位值班，你们不管礼拜天也好…
[030.0 - 040.0] 证有吗？，在报国考了，他结业证有了。…
[040.0 - 048.1] 赶紧打电话叫他们过来…
```

- 速度：串行 4.4s（可并行到 ~1s）；每段 0.7–1.0s。
- ⚠️ **边界失真**：硬切处损失/误听约 1–2 字（如 20s 处"消防是要"→"同时"；30s 处衍出原文没有的"没有结业证是吧？"）。
- 现场录音底噪高（均值 -18.8dB），ffmpeg 静音检测（-20~-35dB 均试过）只在开头安静区有效，**静音切分不可靠**，不能依赖。

**推荐架构（双跑）**：

```text
音频 ──┬── 整段转写（一遍）        → 干净完整文本 → 事实提取 / 笔录生成
       └── 窗口分段转写（~10s/段） → 带时间范围的锚点文本 → 证据回溯定位
```

两遍文本高度相似，LLM 对齐成本低；笔录正文用整段文本（无边界失真），时间锚点用分段文本。窗口加 1s 重叠可进一步减轻边界问题。

## 6. 说话人分离能力探测（2025-08-22 补充）

业务方询问分离可行性，分两层验证：

### 6.1 声学级分离（按声音区分说话人）

| 路径 | 结果 |
|---|---|
| `qwen3-asr-flash` | ❌ 不支持，输出为无说话人标记的连续文本流 |
| `fun-asr-flash-2026-06-15`（网关备选） | ⚠️ 无法调用：chat completions 两种请求形态（`input_audio` / `audio_url`）均返回 HTTP 400 空错误体，该模型在此网关的调用方式不明 |
| `qwen3-asr-flash-realtime`（WebSocket 流式） | 未验证（realtime ASR 一般也不带分离） |
| 本地部署开源分离（FunASR CAM++ / 3D-Speaker / pyannote） | 理论可行，但引入新组件与模型文件，背离"单一可配置端点"策略，MVP 不建议 |

**结论：网关上暂无现成的声学分离能力。**

### 6.2 语义级问/答归属（笔录的实际需求）：✅ 验证通过

用 `qwen3.7-flash` 对 1.mp4 真实转写文本做轮次切分 + 问/答归属，一次调用 26.7s，输出结构化 JSON：

```json
[
  {"role": "问", "text": "负责人，你们值班室的这个消防值班的人呢？"},
  {"role": "答", "text": "今天是礼拜天，他休息。"},
  {"role": "问", "text": "礼拜天休息？你们这个24小时的消防是要24小时在岗在位值班的。"},
  ...共 10 轮
]
```

- 归属准确、顺带修正了 ASR 错字（`在报国考`→`正在报考中`、`24h`→`24小时`）；
- 两人问答场景下检查人员与单位人员的语言模式差异大，LLM 归属可靠；
- ⚠️ 模糊轮次仍会归错（演示中"对，只有结业证"被并入问句），**必须保持"AI 候选 + 人工确认"机制**（PRD §7.3 不得猜测身份的要求不变）；
- 与窗口分段的时间锚点结合，每轮可同时标注大致时间范围。

**结论：笔录的"问：/ 答："归属用语义方案即可满足，无需声学分离。**

## 7. 结论

1. ✅ **`qwen3-asr-flash` 转写方案验证通过**：真实检查视频（46–48s）1.5–1.7s 出结果，中文执法口语质量可用，满足 PRD §16"至少一种经过验证的可配置方案"。
2. ✅ 带时间范围转写有可行兜底：**客户端窗口分段 + 双跑架构**（§4），纯 ffmpeg + 现有 API，零额外依赖。
3. ⚠️ 遗留（不阻塞 MVP 启动，开发期解决）：
   - 分段窗口参数（窗长/重叠）需用更多样本调优；
   - `qwen3-asr-flash-realtime`（WebSocket 流式，通常带句级时间戳）可作为更优解另行验证；
   - 单文件时长/大小上限未测到边界（MVP 视频 1 分钟内，当前余量充足）；
   - 调用失败时的错误格式已观测到一种（400 空错误体），重试/降级逻辑需按 PRD §4 实现。
